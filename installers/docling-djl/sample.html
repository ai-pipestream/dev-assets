Pipestream Parse + Embed Smoke Test

This is a sample document used to verify that docling can parse structured content into Markdown, and that DJL Serving can turn text into sentence embeddings.

Why this exists

The embedder module health-gates on a reachable DJL Serving backend with the MiniLM models loaded, and the parser module uses docling for heavy document conversion (PDFs, scans, complex layouts). This installer proves both inference services work on a given machine, on GPU and on CPU.
